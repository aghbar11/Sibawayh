# LDC data

Licensed corpora live here. **Nothing in this directory is committed except this file.**

## LDC2018T08 — 2007 CoNLL Shared Task (Arabic & English)

Prague Arabic Dependency Treebank in CoNLL-X format: analytical functions in the DEPREL
column (`Pred`, `Sb`, `Obj`, `Atr`, `AuxP`, `PredP`), gold diacritics, gold morphology.

Obtain via the LDC catalog under an institutional membership, extract here:

    tar xzf LDC2018T08.tgz -C data/ldc/
